## 二、数据库脚本

脚本：`script/sql/postgres/iot_pay.sql`

- `iot_pay_order`（支付订单表，唯一索引 `order_no`）
  - 状态机：`0 待支付 → 1 已支付 → 3 已退款`；`0 待支付 → 2 已关闭`
- `iot_pay_refund`（支付退款单表，唯一索引 `refund_no`）
  - 状态：`0 退款中 / 1 退款成功 / 2 退款失败`
- `iot_pay_channel_config`（支付渠道配置表，唯一索引 `config_key`）
  - 表驱动、支持多商户/多渠道热切换（与 `sys_oss_config` 同范式）
- 菜单与权限：二级菜单「支付管理」(menu_id=1900000000000003001) + 按钮权限 `iot:pay:create / query / refund / config`，授权超管角色
- 种子数据：模拟支付渠道 `config_id=1900000000000004001`（config_key=`mock`）

导入方式：

```bash
docker exec -i ruoyi-postgres psql -U postgres -d ruoyi < script/sql/postgres/iot_pay.sql
```

## 五、HTTP 接口清单（前缀 `/iot/pay`）

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/list` | `iot:pay:list` | 分页查询支付单 |
| GET | `/refund/list` | `iot:pay:list` | 分页查询退款单 |
| POST | `/create` | `iot:pay:create` | 统一下单，返回 orderNo / codeUrl |
| GET | `/query/{orderNo}` | `iot:pay:query` | 按支付单号查单 |
| POST | `/refund` | `iot:pay:refund` | 发起退款（须已支付、金额不超过支付额） |
| GET | `/channels` | `iot:pay:config` | 查询启用的渠道配置 |
| POST | `/notify/{channel}` | 免鉴权 | 渠道异步回调，返回渠道应答（如 `success`） |
