登录流程：

```
前端 login 页 ──▶ POST /auth/login (账号/密码/验证码/租户)
        │
        ├─ CaptchaController 校验验证码（存于 Redis）
        ├─ PasswordAuthStrategy 校验密码
        └─ Sa-Token 签发 Token → 返回前端，后续请求头 Authorization 携带
```

## 7. 安全建议（生产）

1. **更换全部默认密码**：平台账号、PostgreSQL、Redis、Nacos、EMQX、MinIO、Spring Boot Admin / SnailJob / SnailAI 控制台。
2. **更换服务令牌**：SnailJob / SnailAI 的 token、`NACOS_AUTH_TOKEN`。
3. **更换 RSA 密钥对**：`api-decrypt` 的公私钥与前端 `.env` 中的 `VITE_APP_RSA_*` 成对替换。
4. **关闭匿名连接**：将 `EMQX_ALLOW_ANONYMOUS` 设为 `false` 并配置认证。
5. **关闭接口加密调试**：确保 `VITE_APP_ENCRYPT` 与后端 `api-decrypt.enabled` 状态一致。
6. **限制端口暴露**：仅对外暴露 80（或 443），其余中间件端口不应公开。
