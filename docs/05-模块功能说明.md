## 3. device · 产品与设备

**职责**：IoT 产品定义、设备实例管理、物模型与分组归属。

| 类 | 类型 | 说明 |
| --- | --- | --- |
| `IotProductController` | 控制器 | 产品 CRUD，前缀 `/iot/product` |
| `IotDeviceController` | 控制器 | 设备 CRUD，前缀 `/iot/device` |
| `IotProduct` / `IotDevice` | 领域实体 | 产品/设备 |
| `IotProductBo` / `IotDeviceBo` | 入参 | 新增/修改 |
| `IotProductVo` / `IotDeviceVo` | 出参 | 查询返回 |
| `IotProductMapper` / `IotDeviceMapper` | Mapper | MyBatis-Plus |

**典型流程**：先建产品（定义协议、物模型）→ 在其下注册设备 → 设备上报数据（见 collect）。

---

## 4. permission · 三线权限

**职责**：分组（数据线）、数据集（数据线）、应用（服务线）的授权管理。

| 类 | 前缀 | 说明 |
| --- | --- | --- |
| `IotGroupController` | `/iot/group` | 设备分组管理 |
| `IotDatasetController` | `/iot/dataset` | 数据集管理与角色授权 |
| `IotAppController` | `/iot/app` | 应用管理与角色/数据集关联 |

**领域模型与关联**：

| 实体 | 含义 |
| --- | --- |
| `IotGroup` | 分组 |
| `IotDataset` | 数据集 |
| `IotApp` | 应用 |
| `IotAppRole` | 应用-角色 |
| `IotAppDataset` | 应用-数据集 |
| `IotDatasetRole` | 数据集-角色 |

通过角色串联，实现“角色 → 可访问的应用 / 数据集 / 分组”的细粒度授权。

---

## 5. collect · 数据采集

**职责**：设备数据上行接入、Kafka 投递、Elasticsearch 时序落库。

| 类 | 说明 |
| --- | --- |
| `MqttDeviceDataSubscriber` | 订阅 EMQX 设备主题（mica-mqtt），组装消息 |
| `DeviceDataKafkaProducer` | 将采集消息投递到 Kafka |
| `DeviceDataKafkaConsumer` | 消费 Kafka 消息，写入 ES / 落库 |
| `IotDeviceDataEsMapper` | Easy-ES 时序索引 Mapper |
| `IotDeviceDataDoc` | ES 文档模型 |
| `DeviceDataMessage` | 采集消息载体 |
| `DeviceCollectController` | HTTP 采集入口，前缀 `/iot/collect/https` |

**数据链路**：

```
设备 ──MQTT──▶ EMQX ──▶ MqttDeviceDataSubscriber ──▶ Kafka ──▶ DeviceDataKafkaConsumer
                                                                      ├─▶ Elasticsearch(时序检索)
                                                                      └─▶ PostgreSQL(关系/最新值)
```

> 也可通过 `POST /iot/collect/https` 以 HTTP 方式接入。

## 7. sso · 统一认证

**职责**：CAS / OAuth2 / OIDC 统一认证与第三方客户端管理。

| 类 | 前缀 | 说明 |
| --- | --- | --- |
| `SsoController` | `/iot/sso` | SSO 票据签发/兑换 |
| `CasController` | — | CAS 协议端点 |
| `OAuth2Controller` | — | OAuth2 授权/令牌端点 |
| `IotOauth2ClientController` | `/iot/oauth2-client` | OAuth2 客户端配置管理 |
| `SsoProperties` | — | SSO 配置（`iot.sso.*`） |
| `IotOAuth2Configuration` / `DbSaOAuth2DataLoader` | — | Sa-Token OAuth2 集成与数据装载 |

**关键配置**（application.yml）：

```yaml
iot:
  sso:
    server-url: http://localhost:8080
    default-client-id: e5cd7e4891bf95d1d19206ce24a7b32e
    ticket-timeout: 300
    oidc:
      id-token-timeout: 3600
```

## 11. pay · 聚合支付

**职责**：统一下单、支付回调、退款，渠道可插拔。

| 类 | 类型 | 说明 |
| --- | --- | --- |
| `PayController` | 控制器 | 前缀 `/iot/pay`（回调 `/iot/pay/notify/**` 免鉴权） |
| `IotPayService` / `IotPayServiceImpl` | 服务 | 支付业务编排 |
| `IPayChannel` | 接口 | 支付渠道抽象 |
| `PayChannelFactory` | 工厂 | 按渠道枚举创建实现 |
| `MockPayChannel` | 实现 | 本地模拟渠道 |
| `IotPayOrder` / `IotPayRefund` / `IotPayChannelConfig` | 实体 | 订单/退款/渠道配置 |
| `PayStatusEnum` / `RefundStatusEnum` / `PayChannelEnum` | 枚举 | 状态与渠道 |
| `PrePayResult` / `PayNotifyResult` / `RefundResult` | 模型 | 统一返回 |

**扩展新渠道**：实现 `IPayChannel` 并在 `PayChannelFactory` 注册即可。

前端页面：`views/pay/index.vue`；接口封装 `src/api/pay.js`；建表脚本 `iot_pay.sql`。

## 12. admin · 启动入口

| 类 | 说明 |
| --- | --- |
| `IotApplication` | Spring Boot 主类（`org.dromara`） |
| `IotServletInitializer` | WAR 部署支持 |
| `AuthController` | 登录/登出/注册 |
| `CaptchaController` | 图形验证码 |
| `IndexController` | 首页信息 |
| `SysLoginService` / `SysRegisterService` | 登录/注册业务 |
| `IAuthStrategy` 及实现 | 多策略登录（密码/短信/邮箱/社交/小程序） |
| `UserLoginSuccessListener` / `UserActionListener` | 登录成功与行为监听 |

**配置要点**（application.yml）：

- `spring.application.name: iot-platform`，端口 `8080`
- Sa-Token：`token-name: Authorization`；放行 `/iot/pay/notify/**`
- SpringDoc：9 个分组（`web/system/device/collect/monitor/sso/archive/report/deploy`）
- 集成组件：message(SSE)、warm-flow、liteflow、mqtt.client、easy-es、spring.ai.mcp、Kafka、Nacos(默认关闭)
- `api-decrypt.enabled: true`（接口加解密）
