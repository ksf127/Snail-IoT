# 查看 / 更新 Secret
kubectl -n iot-platform-dev get secret iot-secret -o yaml
kubectl -n iot-platform-dev create secret generic iot-secret ^
  --from-literal=POSTGRES_USERNAME=postgres ^
  --from-literal=POSTGRES_PASSWORD=postgres ^
  --from-literal=REDIS_PASSWORD=123456 ^
  --from-literal=MINIO_ROOT_USER=ruoyi ^
  --from-literal=MINIO_ROOT_PASSWORD=ruoyi123 ^
  --from-literal=GITHUB_TOKEN=ghp_xxx ^
  --dry-run=client -o yaml | kubectl apply -f -

安全建议与改密

上线前必改 高优先级

数据库、Redis、MinIO、EMQX、Nacos 全部默认口令

sa-token.jwt-secret-key 与 SSO client secret

SnailJob / SnailAI 接入令牌

网络暴露面 中优先级

仅暴露 80 / 443；5432 / 6379 / 9200 / 9092 / 18083 / 9001 / 8848 不对公网开放

K8s 使用 NodePort 30080 / 30081 时配合安全组白名单

凭据管理 中优先级

生产改用 K8s Secret / 外部密钥管理，不写入 yml

admin、test、test1 首次登录后立即改密

GITHUB_TOKEN 使用 fine-grained token，仅授 Contents:Read

审计 持续

开启登录日志与操作日志

定期轮换 JWT 密钥（会使存量 Token 失效）

SSO 票据 TTL 保持 300 秒，不宜放大

常用改密命令

# PostgreSQL
docker exec -it ruoyi-postgres psql -U postgres -c "ALTER USER postgres WITH PASSWORD '新密码';"

# Redis（临时生效，需同步修改 compose 的 --requirepass 与各服务配置）
docker exec -it ruoyi-redis redis-cli -a 123456 --no-auth-warning CONFIG SET requirepass "新密码"

# MinIO（控制台 9001 → Identity → Users 修改，或 mc admin user add）
docker exec -it ruoyi-minio mc admin user add local ruoyi 新密码

# Nacos（控制台 8848/nacos → 权限控制 → 用户 → 修改 nacos 密码）
# 同步更新所有服务的 spring.cloud.nacos.username / password

# 平台账号（前端「系统管理 → 用户管理」重置，或直接改库）
docker exec -it ruoyi-postgres psql -U postgres -d ruoyi -c ^
  "UPDATE sys_user SET password = '' WHERE user_name = 'admin';"
改密后请同步更新本文档、docs/04-账号与初始化说明.md、docker-compose.yml、script/k8s/secret.yaml，避免配置与文档漂移。
