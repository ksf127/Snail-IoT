Snail-IoT · 设备数据采集流程

MQTT 上行 → Kafka 缓冲 → Elasticsearch 时序检索 / PostgreSQL 关系落库

  1. 解耦与削峰：MQTT 订阅与入库之间用 Kafka 缓冲，突发流量不会直接压垮数据库。
  2. 双写分工：PostgreSQL 存储关系型数据与设备维度信息；Elasticsearch 承担高频时序写入与多维检索。
  3. 多协议接入：MqttDeviceDataSubscriber 处理 MQTT；DeviceCollectController 提供 HTTP 入口，二者统一汇入 Kafka。
  4. 可扩展：新增消费逻辑只需订阅同一 Kafka topic，不影响设备端与接入层。
