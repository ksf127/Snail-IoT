Snail-IoT · 设备数据采集流程

MQTT / HTTP 上行 → EMQX → Kafka iot-device-data → ES 时序 + Redis 心跳 + 首次心跳回写 PostgreSQL

  1. 解耦与削峰：MQTT 订阅与下游处理之间用 Kafka（iot-device-data）缓冲，突发流量不会直接压垮数据库。
  2. 落点分工：Elasticsearch 承担高频时序写入与多维检索；Redis 用 5 分钟 TTL 的心跳 Key 判断设备在线；PostgreSQL 只在首次心跳时回写设备在线状态，避免每次上报都写库。
  3. 多协议接入：MqttDeviceDataSubscriber 处理 MQTT；DeviceCollectController 提供 HTTP 入口，二者统一汇入 Kafka。
  4. 可控与可扩展：采集侧限流 100 次 / 60 秒；新增消费逻辑只需订阅同一 Kafka topic，不影响设备端与接入层。
